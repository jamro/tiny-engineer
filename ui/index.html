API reference

JSON HTTP API on port 80. Optional Bearer auth when an access token is configured. Test routes are POST only. GET /auth is always public.

Method Path Description
GET / Web control panel
GET /animations Animations page
GET /tests Hardware tests page
GET /servo Servo control page
GET /config Config page
GET /api This API reference
GET /auth Whether API auth is required (always public)
GET /health Health JSON, no side effects
GET /settings Persistent settings
POST /settings Update settings (see parameters below)
POST /settings/reset Factory reset all settings to defaults
GET /anim Current animation name
POST /anim Set animation (see parameters below)
POST /play Stream a WAV while an animation runs (see parameters below)
POST /test/audio Play tone test
POST /test/audio/bell Play bell WAV from LittleFS
POST /test/screen OLED demo
POST /test/movement All servos exercise
POST /test/led RGB LED cycle
POST /test/servo Move one servo (see parameters below)
POST /setup/servo Setup AP only: slow 0–180° move (see parameters below)
POST /setup/led Setup AP only: light logical RGB or one WS2812 wire byte (see parameters below)
POST /setup/audio Setup AP only: play welcome.wav from LittleFS
POST /setup/oled Setup AP only: preview OLED 180° rotation (see parameters below)

POST /settings — query params (at least one required):

Param Type Range
sleep_timeout integer 1–1440 minutes (positive)
hostname string 1–31 chars, letters/digits/hyphen
volume integer 0–100 percent (speaker gain)
welcome integer 0 or 1 (boot welcome animation)
serial_log integer 0 or 1 (USB serial debug logging)
continuous_timeout integer 1–1440 minutes
loading string progress or sleep_inertia (boot screen; next reboot)
eyes_style string classic, kaomoji, cover, or dots (OLED eyes look; immediate)
access_token string 0–64 printable ASCII; empty clears (disables auth)
wifi_ssid string 1–32 chars; setup AP only; requires wifi_password
wifi_password string 0–63 chars; setup AP only; tested before save
servo_mins string 5 comma-separated ints 0–180; setup AP only; requires servo_maxs
servo_maxs string 5 comma-separated ints 0–180; setup AP only; each max > min
rgb_order string RGB, RBG, GRB, GBR, BRG, or BGR; setup AP only; default GRB
oled_rotate_180 integer 0 or 1; setup AP only; default 0

WiFi credentials, servo min/max, RGB LED mapping, and OLED rotation can only be set in setup AP mode. During setup, hostname may be sent with wifi_ssid and wifi_password (same hostname rules as Config). During setup (credentials not saved), control APIs return 503 wifi not configured; POST /setup/servo, POST /setup/led, POST /setup/audio, and POST /setup/oled stay available. Change WiFi later via factory reset. Servo ranges, RGB mapping, and screen rotation survive factory reset and can be retuned in the setup wizard.

Param Type Range

POST /setup/servo — setup AP only, ~25°/s, no safe-range clamp. Query params:

Param Type Range
all integer 90 (move every joint to 90°)
index integer 0–4 (required with angle when all is omitted)
angle number 0–180

POST /setup/led — setup AP only, no Wi-Fi gate. Lights a logical color or one WS2812 wire byte. Query params:

Param Type Range
color string R, G, or B (logical; uses saved or rgb_order)
rgb_order string RGB, RBG, GRB, GBR, BRG, or BGR (optional with color)
byte string 0, 1, 2, or off (omit or off releases the hold)

POST /setup/audio — setup AP only, no Wi-Fi gate. Plays welcome.wav from LittleFS. No query params.

POST /setup/oled — setup AP only, no Wi-Fi gate. Preview OLED rotation and draw THIS WAY UP. Omit rotate_180 to restore the provisioning screen. Query params:

Param Type Range
rotate_180 integer 0 or 1 (omit to restore provisioning text)

Tiny Engineer setup

Step 1 of 5 · Servos

Attach the printed parts

All joints use the full 0–180° electrical scale. 90° is shaft center, not the middle of the safe band.

Press each printed part onto the servo shaft at rest: head toward the laptop, neck straight, hands down, body centered in the chair. Snug the shaft screws.

Find safe ranges

Move one joint at a time with the buttons. Stop before cables pull taut or parts collide. The bar is a guide only. Stock limits are pre-filled. Switching tabs leaves the other joints where they are.
