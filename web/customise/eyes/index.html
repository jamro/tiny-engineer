Eye styles

Give the robot a different look. Each style redraws the same animations — blinks, glances, moods — with its own face. Pick one in the web config at http://tiny-engineer.local.

  • eyes_style

    classic

    Procedural rounded eyes — the stock look with blinks and glances.

  • eyes_style

    kaomoji

    Animated faces from the expression library — idle, happy, thinking, and more on device.

  • eyes_style

    dots

    Minimal 12×12 circles that track the classic pose — blinks shrink them, glances move them.

  • eyes_style

    kawaii

    Round eyes, big pupils, blush, and a talking mouth — each animation has its own mood.

  • eyes_style

    evil

    Solid white scowling silhouettes — pointed high outers, rounded low inners, always menacing.

Set the style on your robot in the web config at http://tiny-engineer.local. A sixth style, cover, is for eye-hole mask mods and is not shown here.
