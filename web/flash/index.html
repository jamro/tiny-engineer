Prepare the board

Push the ESP32 module into the sockets on the main board. Line it up with the USB mark printed on the board. Use a USB-C data cable into the board’s USB-C. Do not plug into the small port on the ESP32 module.

Chrome or Edge only.

USB-C data cable (charge-only cables fail). Hold BOOT on the module if the port is missing.
